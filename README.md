# Git Workshop Web Presentation

تطبيق عرض تفاعلي لورشة:

**العمل الجماعي وإدارة المشاريع البرمجية باستخدام GitHub و GitLab**

## التشغيل

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## المسارات

- `/` العرض الرئيسي مع 35 شريحة.
- `/lab` وضع التطبيق العملي مع checklist و progress bar.
- `/speaker` وضع المحاضر: الشريحة الحالية، التالية، الملاحظات، والمؤقت.

## اختصارات العرض

- `ArrowRight` أو `Space`: التالي.
- `ArrowLeft`: السابق.
- `F`: Fullscreen.
- `D`: Dim mode.
- `S`: إظهار/إخفاء Speaker Notes.
- `/`: فتح البحث داخل الشرائح.
- `Esc`: إغلاق البحث أو الملاحظات.
- `E`: Export PDF عبر طباعة المتصفح.

## Stack

React + Vite + TypeScript + Tailwind CSS + Framer Motion + Lucide Icons + Mermaid + Prism.
